# Kartkówka INF.03 - Obsługa danych (Grupa 2)

## 1. Struktura HTML

W pliku `index.html` przygotuj odpowiednią strukturę formularza.

**Wymagania:**

* **Pierwsza para:** Etykieta "Nazwa gościa" oraz pole tekstowe.
* **Druga para:** Etykieta "Liczba nocy" oraz pole typu liczbowego.
* **Przycisk:** Napis "Zarezerwuj".
* **Dostępność:** Połącz etykiety z polami za pomocą atrybutów `id` oraz `for` (zgodnie z wytycznymi WCAG).

## 2. Skrypt JavaScript

Napisz skrypt, który po kliknięciu przycisku:

1. Pobierze wartości z obu pól do zmiennych.
2. **Sprawdzi (walidacja):** czy nazwa gościa nie jest pusta oraz czy liczba nocy jest liczbą większą od zera.
3. **Wypisze w konsoli:**
    * Jeśli dane są poprawne: `Gość: [Nazwa], Całkowity koszt (150 zł/noc): [Liczba nocy * 150]`.
    * Jeśli dane są błędne: `Błąd danych!`.
