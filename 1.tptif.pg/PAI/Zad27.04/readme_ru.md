# Задание: Получение и проверка данных (INF.03)

## Шаг 1: Структура HTML

В файле `index.html` создайте структуру, используя следующий сокращенный синтаксис Emmet (без использования блока `<form>`):

```text
(label+input)*2+button
```

**Технические требования:**

1. **Первое поле:** Метка (label) "Имя", поле типа text.
2. **Второе поле:** Метка (label) "Возраст", поле типа number.
3. **Кнопка:** Надпись "Проверить данные".
4. **Доступность:** Каждый тег `label` должен быть связан с соответствующим полем `input` с помощью атрибутов `for` и `id`.

## Шаг 2: Скрипт JavaScript

В файле `script.js` (или внутри тега `<script>`) напишите код, который:

1. Будет запускаться при нажатии на кнопку.
2. Считает значения из обоих полей в переменные.
3. **Выполнит валидацию:**
   * Проверит, что поле "Имя" не пустое.
   * Проверит, что поле "Возраст" содержит значение больше 0.
4. **Выведет результат в консоль:**
   * Если данные верны: `Witaj [Имя], Twój wiek to [Возраст]`.
   * Если данные неверны: `Wprowadzono niepoprawne dane`.
