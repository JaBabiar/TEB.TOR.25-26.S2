# Podstawowe operacje biblioteki MATH
- `Math.ceil(cyfra)` - Zaokrąglenie w góre 
- `Math.floor(cyfra)` - Zaokrąglenie w dół 
- `Math.round(cyfra)` - Zaokrąglenie 
- `Math.random()` - Generacja losowej cyfry z przedziału od 0 do 1 
## Podstawowe losowanie

    Math.random() * (max - min) + min
    let randomInt = Math.round(random)
