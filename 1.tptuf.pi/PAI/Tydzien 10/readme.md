
# 🌗 Przełącznik trybu jasny/ciemny — zadanie z lekcji

## 📄 HTML

### Wymagania:
- Nadaj elementowi `<body>` identyfikator `canvas`
- Dodaj przycisk, który będzie zmieniał tryb

### Przykład:

```html
<body id="canvas" class="light">
    <button id="modeBtn">Zmień tryb</button>
</body>
```

---

## 🎨 CSS

### Wymagania:
- Klasa `.dark`:
  - tło: `#333`
  - tekst: `#fefefe`
- Klasa `.light`:
  - tło: `#f3f3f3`
  - tekst: `#1c1c1c`


## ⚙️ JavaScript

### Wymagania:
- Pobierz `<body>` do zmiennej
- Pobierz przycisk do zmiennej
- Po kliknięciu:
  - jeśli `body` ma klasę `dark` → zmień na `light`
  - jeśli `light` → zmień na `dark`
