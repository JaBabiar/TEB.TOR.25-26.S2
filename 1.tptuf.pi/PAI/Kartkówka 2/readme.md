# Kartkówka INF.03 - Obsługa danych (Grupa 3)

## 1. Struktura HTML

W pliku `index.html` przygotuj odpowiednią strukturę interfejsu.

**Wymagania:**

* **Pierwsza para:** Label "Tytuł filmu" oraz pole tekstowe.
* **Druga para:** Label "Liczba biletów" oraz pole typu liczbowego.
* **Przycisk:** Napis "Oblicz koszt".
* **Dostępność:** Połącz etykiety z polami za pomocą atrybutów `id` oraz `for` (zgodnie z wytycznymi WCAG).

## 2. Skrypt JavaScript

Napisz skrypt, który po kliknięciu przycisku:

1. Pobierze wartości z obu pól do zmiennych.
2. **Sprawdzi (walidacja):** czy tytuł filmu nie jest pusty oraz czy liczba biletów jest liczbą większą od zera.
3. **Wypisze w konsoli:**
    * Jeśli dane są poprawne: `Film: [Tytuł], Całkowity koszt (25 zł/bilet): [Liczba biletów * 25]`.
    * Jeśli dane są błędne: `Błąd danych!`.
