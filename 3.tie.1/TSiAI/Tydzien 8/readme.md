# Kartkowka 

## HTML 
Stwórz formularz zawierający następujące pola tekstowe/numeryczne
- Imie ucznia 
- Nazwisko Ucznia 
- ocene ucznia 
oraz przycisk wykonujący funkcje po kliknięciu 

## JS (funkcja po kliknięciu)
- Skrypt pobiera dane
- Sprawdza czy pola są wypełnione 
- Wypisuje <imie ucznia >  <nazwisko ucznia> otrzymał ocenę: <ocena>
> Zadanie na 6 - Sprawdza czy wartość oceny jest większa od 1 i mniejsza od 6
