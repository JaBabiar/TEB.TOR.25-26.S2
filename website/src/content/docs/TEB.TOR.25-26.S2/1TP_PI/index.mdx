# Kartkówka INF.03 - Obsługa danych (Grupa 4)

## 1. Struktura HTML

W pliku `index.html` przygotuj odpowiednią strukturę interfejsu.

**Wymagania:**

* **Pierwsza para:** Label "Imię i nazwisko klienta" oraz pole tekstowe.
* **Druga para:** Label "Liczba miesięcy" oraz pole typu liczbowego.
* **Przycisk:** Napis "Oblicz koszt karnetu".
* **Dostępność:** Połącz etykiety z polami za pomocą atrybutów `id` oraz `for` (zgodnie z wytycznymi WCAG).

## 2. Skrypt JavaScript

Napisz skrypt, który po kliknięciu przycisku:

1. Pobierze wartości z obu pól do zmiennych.
2. **Sprawdzi (walidacja):** czy imię i nazwisko nie jest puste oraz czy liczba miesięcy jest liczbą większą od zera.
3. **Wypisze w konsoli:**
    * Jeśli dane są poprawne: `Klient: [Imię i nazwisko], Całkowity koszt (110 zł/miesiąc): [Liczba miesięcy * 110]`.
    * Jeśli dane są błędne: `Błąd danych!`.
